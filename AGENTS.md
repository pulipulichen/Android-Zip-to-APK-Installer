# Project rules

- When Codex is connected to GitHub through ChatGPT, use the ChatGPT GitHub connector to read, commit, and update this repository. Do not use the GitHub CLI or Git CLI for GitHub operations in that situation.
- For repository file changes, include this trailer in each commit message, replacing the model placeholder with the model used:
  `Co-authored-by: OpenAI Coding Assistant {model} <noreply@openai.com>`
- When reporting a completed repository change, include the resulting GitHub commit link.
